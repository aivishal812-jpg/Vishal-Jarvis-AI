# Vishal Jarvis AI (Android) — v2.2.0

বাংলা-প্রথম Android AI অ্যাসিস্ট্যান্ট: Gemini টেক্সট চ্যাট, Gemini Live ভয়েস কল, 3D রোবট ক্যারেক্টার এবং ফোন কন্ট্রোল।

## APK ডাউনলোড

1. রিপোর **Actions** ট্যাবে যান → সবশেষ সবুজ (সফল) "Build Android APK" রানে ঢুকুন।
2. নিচে **Artifacts** থেকে `Vishal-Jarvis-<ভার্সন>-APK` ডাউনলোড করুন (zip খুললে `.apk` পাবেন)।
3. অথবা **Releases** অংশ থেকে সরাসরি `.apk` নামিয়ে নিন।
4. ফোনে "Unknown apps install" অনুমতি দিয়ে ইনস্টল করুন। আগের অন্য-কী-তে সাইন করা ভার্সন থাকলে প্রথমবার আনইনস্টল করে নিতে হবে।

## যদি অ্যাপ খুলেই বন্ধ হয়ে যায় (crash) — এখন ফোনই বলে দেবে কেন

অ্যাপ যদি খোলার সাথে সাথে বন্ধ হয়ে যায়, **আবার খুলুন**। দ্বিতীয়বার ও আর বন্ধ হবে না — বদলে একটা **সাদাসিধা (WebView-হীন) স্ক্রিন** আসবে যেখানে লেখা থাকবে ফোন ঠিক কোন লাইনে আটকেছে, সাথে দুটো বোতাম: **Share this report** (সরাসরি WhatsApp/মেইলে) আর **Start with the graphics turned off**। ওই লেখাটা পাঠালেই সমস্যাটা ধরা যাবে।

কেন এমন: crash যদি WebView চালু হওয়ার *আগেই* হয়, তাহলে JavaScript দিয়ে কিছু দেখানোই সম্ভব না — তাই পুরো ব্যবস্থাটা এখন **native** দিকে:
- `onCreate`-এর প্রতিটা ধাপ guarded (Throwable), ব্যর্থ হলে স্ক্রিনে আসল stack trace।
- crash log এখন **দুই জায়গায়** লেখা হয় — app-private + `Android/data/com.myraa.mobile/files/crash-log.txt` (file manager দিয়ে খোলা যায়)।
- শুরুতে কোনো helper (BeepMuter/Reminder/Proactive/MemoryDb) ব্যর্থ হলেও অ্যাপ খোলে — `catch (Throwable)`।
- WebView না থাকলে/পুরনো হলে সেটাও ধরা পড়ে, অ্যাপ বন্ধ হয় না।
- ১২ সেকেন্ড watchdog + `bridge.pageReady()` — page আটকে থাকলে আসল কারণ দেখায়।



১৮০+ ব্লক build-এর পরও কোনো ফোনে "keeps stopping" এলে এটা এখন **নির্দিষ্টভাবে ধরা যায়**:

1. **থামার কারণ লেখা হয় স্ক্রিনে** — Android-এর WebView/page ১২ সেকেন্ডে শেষ না হলে অ্যাপ খালি থাকার বদলে আসল error দেখায় (tap = retry)।
2. **JS bridge guarded** — contacts/call-log/notification-এর মতো permission ব্লক থাকলে আগে exception bridge পেরিয়ে পুরো process মেরে ফেলত; এখন সেটা normal message হয়, অ্যাপ বন্ধ হয় না।
3. **pre-paint splash** — bundle পার্স হওয়ার আগেই crimson "STARTING CORE" স্ক্রিন দেখা যায়, তাই কালো স্ক্রিন আর নেই।
4. **WebGL না থাকলেও চলে** — 3D fail করলে চরিত্রের জায়গায় এক লাইন লেখা আসে, mic আর বাকি সব কাজ করে।
5. **Crash report শেয়ার** — Settings → Crash report: ফোনের লোকাল crash log সোজা WhatsApp/মেইলে পাঠানো যায়। ফোনটা কম্পিউটারে লাগাতে হয় না।
6. **CI**: signing key build-এর আগেই যাচাই হয়, প্রতিটি release-এ `SHA256SUMS.txt` থাকে।

## Stark-workshop HUD — এখন পুরো স্ক্রিন জুড়ে

পুরো ডিসপ্লে এখন একটা HUD: চার কোণে স্পেসিং bracket, দুই পাশে tick rail, উপরে **telemetry strip** (clock · date · link · mode · state · batt · load · turns · facts · uptime), আর স্ক্রিনের চার কোণে ছয়টা লাইভ কার্ড — **SIGNAL ANALYSER**, **VOICE LINK** (মাইকের আসল লেভেল), **MEMORY INDEX**, **NETWORK TRAFFIC**, **REQUEST FLOW**, গেজ কার্ড। বড় স্ক্রিনে দুই পাশে বাড়তি দুটো কার্ড আসে, ছোট স্ক্রিনে নিচের কার্ডগুলো লুকিয়ে যায় যাতে লেখা ঢাকা না পড়ে।
নিচের **টেক্সট বক্স তুলে দেওয়া হয়েছে** — এখন শুধু একটা **crimson mic core**: বললে রিংটা আসল ভয়েস লেভেলে জ্বলে ওঠে, speaking হলে pulse করে, tap করলে Live voice ওঠে/বন্ধ হয়। Suggestion চিপে চাপ দিলে লেখাটা core-এর নিচে জমা থাকে, core চাপলেই পাঠায় — কীবোর্ড লাগে না।

চরিত্রের চারপাশে **Stark Industries ধাঁচের HUD**: gear-tooth রিং, ঘুরতে থাকা arc segment, sweeping beam, মাঝখানে crimson triangle badge — সাথে চারটে ডেটা প্যানেল (SIGNAL ANALYSER waveform, CPU/MEM/BATT/ACT gauge, NETWORK TRAFFIC, REQUEST FLOW), কোণে বড় ঘড়ি ও তারিখ। সব **কোড দিয়ে আঁকা (SVG/canvas)** — কোনো ছবি ডাউনলোড নেই, তাই APK ভারী হয় না।
প্যানেলের সংখ্যা **সত্যি**: ঘড়ি/তারিখ, অ্যাপের মেমরি, ফোনের ব্যাটারি %, online/offline, সেশন সময়, কথোপকথনের turn সংখ্যা। CPU/ACT আসলে অ্যাসিস্ট্যান্টের নিজের ব্যস্ততা — তাই নাম দেওয়া হয়েছে "গেজ", ভুয়া তাপমাত্রা/আবহাওয়া দেখানো হয় না।
চরিত্রটা এখন রিংয়ের **ভেতরে** দাঁড়ায়, আর HUD-ও react করে: কথা বললে SIGNAL waveform ওঠে, state বদলায়।

## চেহারা (সর্বশেষ)

পুরো ইন্টারফেস এখন **futuristic crimson** — গভীর কালচে-লাল ব্যাকগ্রাউন্ড, ধীরে ভাসা crimson aurora, HUD গ্রিড, কোণে targeting bracket, জ্বলজ্বলে mic core আর পেছনে crimson halo।
চরিত্রটি সম্পূর্ণ নতুন করে বানানো: স্তরে স্তরে armour plate (clearcoat metal), কাঁধের pauldron, হাতে **repulsor**, বুকে **arc reactor + halo glow**, vented visor ও jaw, articulated আঙুল, boot ও joint ring — সাথে **procedural studio environment map** (ধাতু সত্যিই কিছু প্রতিফলিত করে) আর **real bloom**।
Settings → Graphics: **Maximum** (bloom + reflections + full detail), **Medium** (ডিফল্ট, glow সহ), **Low** (ব্যাটারি বাঁচাতে glow/reflection বন্ধ)।

| নাম বললেই কল/মেসেজ (লিস্ট নেই) | "baba ke call koro" বা "baba ke whatsapp e message koro" — কোনো লিস্ট, কোনো "কাকে?" প্রশ্ন নেই। ফোন নিজেই বেছে নেয়: আগে আপনি যাকে ঠিক করেছেন (একবার শিখে নেয়), তারপর **recent call history** (যাকে বেশি কল করেন), তারপর হুবহু নাম। উদ্দেশ্যমূলকভাবে আলাদা কয়েকজন হলে যিনি বেশি ফোনে আছেন তাঁকেই নেয়, আর জোরে নাম বলে দেয় যাতে ভুল হলে সাথে সাথে বোঝা যায়। "Call history" অনুমতি দিলে প্রথমবার জিজ্ঞেস করে — না দিলেও কাজ করে, শুধু কম নিখুঁত। Jarvis Pro → "Who a name means" থেকে শেখা নাম দেখা/ভুলে যাওয়া যায়। |
| কথা বলার মাঝে আপনি কথা বললেই থেমে যায় | Jarvis উত্তর পড়া শুরু করলে মাইক্রোফোন খোলা থাকে; আপনি ২-৩ শব্দ বললেই সে **সাথে সাথে থেমে** আপনার কথাটাই নতুন প্রশ্ন হিসেবে নেয়, আর তার উত্তর আগে দেয়। "ok/হুম/হ্যাঁ" বললে বা নিজের গলা স্পিকার থেকে ফিরে এলে থামে না। দীর্ঘ উত্তরের শেষ পর্যন্ত অপেক্ষা করতে হয় না — যেকোনো সময় বাধা দিতে পারেন। |
| রিলায়েবিলিটি | `npm run check` এখন টুল-স্কিমা সিঙ্ক্রনাইজেশন সহ চলে, `scripts/check-java-symbols.py` দিয়ে দ্রুত ক্রস-ফাইল ভুল ধরা হয়, JVM ইউনিট টেস্ট যোগ হয়েছে (বাংলা নরমালাইজার, TTS চাঙ্কিং, ব্যাকগ্রাউন্ড হোয়াইটলিস্ট, PDF এক্সট্রাক্টর), আর Tasks DB আপগ্রেড আর ক্র্যাশ করে না। |

## নিজে বিল্ড করা

- GitHub Actions: `main`-এ push করলেই `.github/workflows/build-apk.yml` APK বানায়।
- Linux/macOS: `ANDROID_HOME=... JAVA_HOME=... bash scripts/build-android.sh`
- Windows: `npm run build:android`
- Android Studio: `android/` ফোল্ডার খুলুন (Gradle wrapper যুক্ত আছে)।

APK সাইনিং: রিপোর `ANDROID_KEYSTORE_BASE64` ও `ANDROID_KEYSTORE_PASSWORD` সিক্রেট থাকলে প্রতিটি বিল্ড একই কী-তে সাইন হয়, ফলে নতুন APK পুরনোটার উপর আপডেট হিসেবে ইনস্টল হবে।
