# Vishal Jarvis AI (Android) — v2.2.0

বাংলা-প্রথম Android AI অ্যাসিস্ট্যান্ট: Gemini টেক্সট চ্যাট, Gemini Live ভয়েস কল, 3D রোবট ক্যারেক্টার এবং ফোন কন্ট্রোল।

## APK ডাউনলোড

1. রিপোর **Actions** ট্যাবে যান → সবশেষ সবুজ (সফল) "Build Android APK" রানে ঢুকুন।
2. নিচে **Artifacts** থেকে `Vishal-Jarvis-<ভার্সন>-APK` ডাউনলোড করুন (zip খুললে `.apk` পাবেন)।
3. অথবা **Releases** অংশ থেকে সরাসরি `.apk` নামিয়ে নিন।
4. ফোনে "Unknown apps install" অনুমতি দিয়ে ইনস্টল করুন। আগের অন্য-কী-তে সাইন করা ভার্সন থাকলে প্রথমবার আনইনস্টল করে নিতে হবে।

## v2.2.0-এ নতুন

| Feature | কীভাবে ব্যবহার করবেন |
|---|---|
| সত্যিকারের ব্যাকগ্রাউন্ড এজেন্ট | ফোন লক থাকলেও বা অ্যাপ বন্ধ থাকলেও ১৭টি নিরাপদ কাজ হয়: রিমাইন্ডার, নোট, আবহাওয়া, ব্রিফিং, ডিভাইস স্ট্যাটাস, টর্চ, ভলিউম, মিডিয়া কী, নোটিফিকেশন পড়া/মোছা, ক্যালেন্ডার পড়া, ইনস্টল করা অ্যাপের তালিকা, SIM তথ্য। কল/মেসেজ/অ্যাপ খোলার মতো কাজ আগের মতোই অনুমতি চায় — মিথ্যে "হয়ে গেছে" বলবে না। |
| স্ক্রিন রিডার (ঐচ্ছিক) | Android Settings → Accessibility → "Vishal Jarvis screen reader" চালু করুন। তারপর "এই স্ক্রিনটা পড়ে শোনাও", "শেষ মেসেজটা কী", "এই ফর্মটা ভরে দাও" — ফর্ম ভরে দেয় কিন্তু নিজে থেকে Send/Submit/Pay কখনো চাপে না। যে স্ক্রিনে টেক্সট-ট্রি নেই (PDF, গেম, কাস্টম ভিউ) সেখানে ফোন নিজে একটা স্ক্রিনশট তুলে মডেলকে দেখায়, ছবি কোথাও সেভ বা আপলোড হয় না। |
| লম্বা উত্তর পুরোটা শোনা | আগে ~৪,০০০ অক্ষরে উত্তর কেটে যেত; এখন বাক্য ধরে ধরে পুরো উত্তর পড়া হয়। |
| বাংলা সংখ্যা/সময় বোঝা | "৮টা ৩০", "সাড়ে সাতটা", "সন্ধ্যা ৬টা", "পৌনে আটটা", "দশ মিনিট পর", "২ ঘণ্টা" — সবই ঠিক সময়ে বদলে যায়। "আজকের আবহাওয়া" এখন আর ভুল করে ওয়েব সার্চ হয় না। |
| অফলাইন ওয়েক-ওয়ার্ড | ফোনে অফলাইন স্পিচ মডেল থাকলে সেটাই ব্যবহার হয় (নেটওয়ার্ক লাগে না); মাইক্রোফোনের ওয়েক-লক শুধু শোনার সময় ধরে রাখা হয়, তাই ব্যাটারি কম যায়। |
| Proactive হেল্প (ঐচ্ছিক) | Jarvis Pro settings → Proactive help: মর্নিং ব্রিফিং (সময় ঠিক করা যায়), মিটিংয়ের আগে রিমাইন্ডার (কত মিনিট আগে ঠিক করা যায়), গুরুত্বপূর্ণ নোটিফিকেশনের ডাইজেস্ট, মিসড কল, OTP — কোড কখনো নোটিফিকেশনে দেখানো হয় না। আর একটি ঐচ্ছিক জায়গা-রুটিন (ভূ-লোকেশন)। ডিফল্টে সব বন্ধ। |
| দীর্ঘমেয়াদি মেমরি | প্রতিটি কথোপকথন ও ফ্যাক্ট SQLite-এ (FTS সার্চ সহ) থেকে যায়। "কাল কী বলেছিলাম", "আমার দোকানের নম্বর কী", "শেষে কী আলোচনা করেছিলাম" — সবই কাজ করে, অ্যাপ বন্ধ করলেও থাকে। |
| ডকুমেন্ট পড়া | চ্যাট বক্সের ক্যামেরা বাটনে চাপ দিয়ে "PDF or text file" বেছে নিন — টেক্সট ফোনেই বের করা হয়, তারপর প্রশ্ন করুন। স্ক্যান করা PDF-এর টেক্সট-লেয়ার থাকে না; সেটা খোলা রেখে স্ক্রিন রিডার ব্যবহার করুন। |
| রিলায়েবিলিটি | `npm run check` এখন টুল-স্কিমা সিঙ্ক্রনাইজেশন সহ চলে, `scripts/check-java-symbols.py` দিয়ে দ্রুত ক্রস-ফাইল ভুল ধরা হয়, JVM ইউনিট টেস্ট যোগ হয়েছে (বাংলা নরমালাইজার, TTS চাঙ্কিং, ব্যাকগ্রাউন্ড হোয়াইটলিস্ট, PDF এক্সট্রাক্টর), আর Tasks DB আপগ্রেড আর ক্র্যাশ করে না। |

## নিজে বিল্ড করা

- GitHub Actions: `main`-এ push করলেই `.github/workflows/build-apk.yml` APK বানায়।
- Linux/macOS: `ANDROID_HOME=... JAVA_HOME=... bash scripts/build-android.sh`
- Windows: `npm run build:android`
- Android Studio: `android/` ফোল্ডার খুলুন (Gradle wrapper যুক্ত আছে)।

APK সাইনিং: রিপোর `ANDROID_KEYSTORE_BASE64` ও `ANDROID_KEYSTORE_PASSWORD` সিক্রেট থাকলে প্রতিটি বিল্ড একই কী-তে সাইন হয়, ফলে নতুন APK পুরনোটার উপর আপডেট হিসেবে ইনস্টল হবে।
