# Vishal Jarvis AI (Android) — v2.1.0

বাংলা-প্রথম Android AI অ্যাসিস্ট্যান্ট: Gemini টেক্সট চ্যাট, Gemini Live ভয়েস কল, 3D রোবট ক্যারেক্টার এবং ফোন কন্ট্রোল।

## APK ডাউনলোড

1. রিপোর **Actions** ট্যাবে যান → সবশেষ সবুজ (সফল) "Build Android APK" রানে ঢুকুন।
2. নিচে **Artifacts** থেকে `Vishal-Jarvis-<ভার্সন>-APK` ডাউনলোড করুন (zip খুললে `.apk` পাবেন)।
3. অথবা **Releases** অংশ থেকে সরাসরি `.apk` নামিয়ে নিন।
4. ফোনে "Unknown apps install" অনুমতি দিয়ে ইনস্টল করুন। আগের অন্য-কী-তে সাইন করা ভার্সন থাকলে প্রথমবার আনইনস্টল করে নিতে হবে।

## v2.1.0-এ নতুন

- স্ক্রিন লক থাকলেও ব্যাকগ্রাউন্ডে "Hey Jarvis" / "জার্ভিস" / "Hey service" শোনে।
- একবারে বলুন: "Hey Jarvis, টর্চ জ্বালাও" — অ্যাপ না খুলে নিচে ছোট কার্ডে উত্তর দিয়ে নিজে বন্ধ হয়ে যায়।
- লক অবস্থায় টর্চ, ভলিউম, গান, রিমাইন্ডার, আবহাওয়া সরাসরি হয়; অ্যাপ খোলা/কল/মেসেজের আগে ফিঙ্গারপ্রিন্ট চায়।
- কম কথা বলে: এক-দুই লাইনের ছোট উত্তর।
- কিবোর্ডের (Gboard) ভয়েস টাইপিং বা অন্য অ্যাপ মাইক ব্যবহার করলে Jarvis নিজে থেকে থেমে যায়, পরে আবার শোনে।

## নিজে বিল্ড করা

- GitHub Actions: `main`-এ push করলেই `.github/workflows/build-apk.yml` APK বানায়।
- Linux/macOS: `ANDROID_HOME=... JAVA_HOME=... bash scripts/build-android.sh`
- Windows: `npm run build:android`
- Android Studio: `android/` ফোল্ডার খুলুন (Gradle wrapper যুক্ত আছে)।

APK সাইনিং: রিপোর `ANDROID_KEYSTORE_BASE64` ও `ANDROID_KEYSTORE_PASSWORD` সিক্রেট থাকলে প্রতিটি বিল্ড একই কী-তে সাইন হয়, ফলে নতুন APK পুরনোটার উপর আপডেট হিসেবে ইনস্টল হবে।

## দরকার

- Android 8.0+ ফোন, নিজের Gemini API key (অ্যাপের Settings-এ দিন)।
- ওয়েক ওয়ার্ডের জন্য Google অ্যাপের স্পিচ রিকগনাইজার।
